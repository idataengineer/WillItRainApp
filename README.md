# Will It Rain On My Parade? 🌦️

This is a hackathon project built during NASA Space Apps Challenge 2025.

## Features
- Input city name or latitude,longitude to get weather forecast.
- Meteomatics hourly precipitation forecast displayed as a chart.
- Chatty AI/ML prediction layer with friendly advice.
- Works for any city worldwide (via OpenStreetMap geocoding).

## Setup
1. Clone the repo
2. Create a Python virtual environment
3. Install dependencies:
   ```bash
   pip install streamlit pandas requests
